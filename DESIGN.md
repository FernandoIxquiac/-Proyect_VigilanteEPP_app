# DESIGN.md - Reglas de Diseno Visual

## Regla 1: Sin Emojis en la UI
PROHIBIDO EL USO DE EMOJIS en cualquier elemento visible de la interfaz, etiquetas, botones, títulos, subtítulos, captions, markdowns, opciones de selectbox/radio, logs o documentación. Usar únicamente texto claro en español o glifos Unicode industriales sobrios (ej. ●, ■, ◈, ◉, ▲, ≡, ⚙).

## Regla 2: Idioma
Toda la interfaz en espanol. Comentarios de codigo pueden ser en espanol o ingles.

## Regla 3: Tema
Soporte obligatorio para Dark Mode y Light Mode. Los colores siguen las variables CSS definidas en styles/styles.py.
